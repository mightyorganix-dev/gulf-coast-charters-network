# What NOT to Have Captains Sign on the First Handshake  
## GCCN Dock Visit — Field Guardrails

**DRAFT — FOR OWNER + COUNSEL**  
**Not legal advice.** Purpose: keep the first dock visit **premier, fair, and light**—get a clean participation path for one signature private trip without over-lawyering or creating false comfort.

## Do sign on first handshake (after counsel green-lights the packet)
1. Final counsel-approved **Operator / IC Participation Agreement** (one-pager).  
2. **Trip Listing Addendum** for the first signature private trip (price, deposit %, cancel/weather).  
3. **Compliance Checklist acknowledgment** (with COI/USCG copies collected—not “approved as legally sufficient” by dock staff).

## Do NOT put in front of them on first handshake
| Avoid on day one | Why (ops risk) |
|------------------|----------------|
| Long “master services” tome (20+ pages) nobody can read at the dock | Slows trust; invites unsigned piles; errors |
| Exclusive territory / non-compete / “you only book with us” | Conflicts with non-exclusive marketplace model; counsel-heavy |
| Employment offer letters, W-4s, or “crew handbook as employees” | Undercuts IC posture; classification risk—**CPA/counsel only** |
| Personal guarantee of Network debts or unlimited indemnity they didn’t negotiate | Unfair optics; counsel must draft any indemnity |
| Blank or open-ended fee schedules (“fee as we decide later”) | Ambiguity → disputes; put % on the Addendum |
| Guest waivers **for the captain to invent** or copy from a random website | Waiver quality is counsel + insurance broker work |
| Statements that Network “inspected” or “certified” the vessel as seaworthy | Network is asset-light marketplace—don’t create survey liability |
| “You’re legally fine / USCG approved because we checked the box” | Checklist ≠ legal opinion |
| Marketing affidavits promising catch rates or scarcity claims | Marketing accuracy; no guaranteed catch |
| Multi-state expansion addenda “just in case” for other coasts | Clone markets need **local counsel** first |
| IP assignment of the captain’s personal brand / social accounts | Overreach for first meeting |
| Confession-of-judgment, onerous arbitration surprise terms without counsel explanation | Fairness + enforceability—counsel gates |
| Anything asking for passwords, Stripe login, or full bank portal access beyond payout onboarding Network actually needs | Security / trust |
| Backdated documents or “sign this later effective last month” | Bad hygiene; don’t |

## Soft rules for the dock visit
- Bring **one printed packet** (or one e-sign envelope), not five versions.  
- Let them take counsel time; **no pressure-sign**.  
- Collect COI + credential **copies**; if expired or missing, **hold listing**—don’t “sign now, fix later” for live guest bookings.  
- One signature trip first; add more Trip Listing Addenda later.  
- Sister brand **Gulf Coast Spearfishing**: mention as optional cross-list only if the trip type fits and counsel-approved GCS rules exist—don’t force a second brand stack on day one.  
- Never send external legal notices or “cease and desist” style letters from this role without explicit owner approval + counsel.

## If they ask “is this enough legally?”
Honest answer: **These are ops templates. Your lawyer and insurance broker sign off before we rely on them.** Network will not tell you that you can skip counsel for entity, insurance, maritime liability, or IC classification.
